# Lapin

Projet de création de petites vidéos pour TikTok, depuis les images de référence jusqu'à l'animation finale.

## Organisation

Chaque vidéo possède son propre dossier dans `videos/`. La première est préparée dans `videos/video-001/` :

```text
videos/video-001/
├── 01-references/          Images d'inspiration et image de départ
├── 02-storyboard/          Plan des scènes et vignettes du storyboard
│   ├── storyboard.md       Modèle à compléter avant l'animation
│   └── vignettes/
├── 03-elements/            Éléments utilisés dans la vidéo
│   ├── personnages/
│   ├── decors/
│   └── audio/
├── 04-animation/           Fichiers de travail du logiciel d'animation
└── 05-exports/
    ├── brouillons/         Versions de travail à vérifier
    └── tiktok/             Vidéos finales prêtes à publier
```

Le [guide de rangement](docs/rangement.md) explique les noms de fichiers et les étapes de travail.

## Première étape

Placer l'image de départ dans `videos/video-001/01-references/`, puis compléter le storyboard ensemble. Aucun scénario ou contenu d'animation n'est encore défini.
