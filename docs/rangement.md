# Guide de rangement

## Une vidéo, un dossier

Utiliser `video-001`, puis `video-002`, etc. Chaque dossier conserve ses références, son storyboard, ses éléments, ses fichiers d'animation et ses exports. Pour une nouvelle vidéo, reprendre la même organisation avec un storyboard vierge.

## Noms de fichiers

Utiliser des noms courts, sans espaces, avec une version lorsque le fichier évolue. Exemples :

- `reference-01.png`
- `scene-01-v01.png`
- `personnage-lapin-v01.png`
- `video-001-v01.mp4`

Conserver l'image de référence originale. Enregistrer les retouches dans un nouveau fichier. Garder les fichiers de travail dans `04-animation/` et les vidéos exportées dans `05-exports/`.

Les fichiers `.gitkeep` permettent de conserver les dossiers vides dans Git ; ils ne sont pas des éléments de la vidéo.

## Ordre de travail

1. Rassembler les références dans `01-references/`.
2. Définir et valider les scènes dans `02-storyboard/storyboard.md`, avec les vignettes dans `02-storyboard/vignettes/`.
3. Préparer les personnages, décors et sons dans `03-elements/`.
4. Créer l'animation dans `04-animation/`.
5. Vérifier les exports dans `05-exports/brouillons/`, puis ranger la version finale dans `05-exports/tiktok/`.

## Format cible

Prévoir une vidéo verticale au format 9:16, généralement 1080 × 1920 pixels. La durée, le style, le son et l'outil d'animation seront définis pendant la préparation du storyboard.

Avant publication, vérifier les droits d'utilisation des images et des sons, ainsi que le cadrage et la lisibilité des textes dans TikTok.
